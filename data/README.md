# Синтетический набор copy task

Данные создаются в `src/transformer/copy_task.py` и не являются внешним датасетом.
`copy_splits.json` фиксирует 1024 train / 128 validation / 128 final test примеров.
Значения, seeds, диапазоны длины и словарь описаны в README.
Первые development splits сохранены отдельно в reports/experiments/600_steps/.
